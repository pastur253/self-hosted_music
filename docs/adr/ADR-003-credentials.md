# ADR-003. Учётные данные для записи плейлистов

**Статус:** принято

**Контекст.** Subsonic API не позволяет создать плейлист «от имени» другого
пользователя, кроме использования его учётных данных или токена.

**Решение.** В MVP MixCore работает от сервисной учётной записи `mix-admin`
(секрет в Docker secret, монтируется read-only), а права и членство хранятся
в реестре `state/collab/*`. Синхронизация состава выполняется через
`updatePlaylist` от сервисной учётной записи.

**Следствия.** Плейлисты миксов принадлежат сервисной учётной записи и видны
всем пользователям (public). Персональные списки «избранное пользователя»
остаются в Navidrome. Индивидуальные права обеспечиваются реестром MixCore,
а не правами Navidrome.

**Альтернативы.** Хранение учётных данных каждого пользователя (шифрование at-rest)
не выбрано: сложность и риск утечки не оправданы для домашнего развёртывания.

# ADR-001. Фиксация версий Navidrome и Feishin

**Статус:** принято

**Контекст.** Feishin в режиме `navidrome` использует часть нативных эндпоинтов
`/api`, которые Navidrome не документирует и может менять без предупреждения.

**Решение.** Шлюз подключается к Navidrome по документированному Subsonic API.
Feishin в Docker-развёртывании запускается с `SERVER_TYPE=subsonic`
(ADR-004). Проксирование нативных `/api` включается флагом
`MIX_PROXY_NATIVE_API` и по умолчанию выключено.

**Следствия.** Нативные оптимизации Navidrome недоступны; обновление Navidrome
не должно ломать интеграцию. Теги версий фиксируются в `deploy/.env`.

**Проверки.** V-01 (какие эндпоинты вызывает Feishin), V-06 (работа редиректов
через прокси).

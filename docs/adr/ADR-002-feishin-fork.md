# ADR-002. Форк Feishin отложен

**Статус:** отклонено на фазе MVP

**Контекст.** Feishin не имеет plugin API. Панель миксов и realtime-совместные
плейлисты внутри Feishin возможны только собственным форком (GPL-3.0).

**Решение.** В MVP и P1 форк не поддерживается. Функции, недоступные в Feishin,
реализуются в MixWeb (PWA). Feishin используется как клиент прослушивания:
сгенерированные миксы видны как обычные плейлисты Navidrome.

**Пересмотр.** Форк рассматривается в P2 при наличии бюджета на rebase и
собственный канал релизов (риск R-02).

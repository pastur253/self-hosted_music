# ADR-009. Технологический стек

**Статус:** принято

**Решение.**

| Слой | Стек |
|---|---|
| MixCore | Python 3.12, FastAPI, Uvicorn, Pydantic v2, httpx, APScheduler, numpy |
| MixGateway | Python 3.12, Starlette/FastAPI, httpx |
| MixWeb | TypeScript, React, Vite, TanStack Query, Zustand, Tailwind CSS |
| Хранилище | Файлы JSON/NDJSON/gzip; `sqlite3` только как индекс векторов |
| Reverse proxy | Caddy (TLS + статика MixWeb) |
| ИИ | Ollama (опционально), HTTP API |

**Обоснование.** Единый язык на бэкенде сокращает число инструментов и позволяет
переиспользовать экосистемы данных/ИИ без моста. Шлюз не буферизует аудио
(307-редирект), поэтому выигрыш Go для прокси минимален. Статика MixWeb раздаётся
Caddy, чтобы не держать отдельный web-контейнер.

**Ограничения.** Производительность шлюза при сотнях одновременных потоков;
эмбеддинги на CPU; генерация текста локальной моделью — все учтены в разделе
7.0.7 ТЗ.
